# Dharohar - Heritage & Cultural Preservation Platform

A modern interactive web platform dedicated to exploring, preserving, and celebrating India's tangible and intangible cultural heritage.

## Features

- **Interactive Heritage Map**: Explore heritage sites, architectural wonders, and regional folklore with interactive maps powered by Leaflet.
- **Cultural Passport**: Track cultural exploration journeys, discover regional landmarks, and earn heritage badges.
- **AR Walk**: Augmented Reality walkthrough experiences bringing ancient monuments and traditions to life.
- **Preserve & Contribute**: Community crowdsourced platform to document disappearing folklore, oral histories, art forms, and indigenous practices.
- **Heritage Vitality Dashboard & Heatmap**: Data-driven insights and danger indexes tracking threatened cultural traditions and endangered heritage sites.
- **Interactive Heritage Quizzes**: Engaging trivia and learning challenges to test and deepen your knowledge of Indian heritage.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Maps**: Leaflet + React Leaflet
- **Routing**: React Router v8
- **Icons**: Lucide React
