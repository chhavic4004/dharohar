 # Dharohar

 A React and Vite website for exploring and preserving India's cultural heritage.

## Requirements

- Node.js 22
- pnpm 10.34.3

## Start the project

Open PowerShell in the project folder:

```powershell
cd "D:\Dharohar website prototype"
```

Install pnpm globally if the `pnpm` command is not available:

```powershell
npm install --global pnpm@10.34.3
```

Install the project dependencies:

```powershell
pnpm install
```

Start the development server:

```powershell
pnpm dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Other commands

 Build the application for production:

```powershell
pnpm build
```

 Preview the production build locally:

```powershell
pnpm preview
```

 Format the source files:

```powershell
pnpm format
```
